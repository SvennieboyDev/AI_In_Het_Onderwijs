# AI in het Onderwijs — NakijkAssistent

Nakijktool voor Nederlands docenten voor het vak O&amp;O. Dit project heet AI in het
Onderwijs en verlaagt de werkdruk van Nederlands docenten door het nakijken van
verslagen sneller en overzichtelijker te maken.

## Status: prototype

Dit is een eerste, klikbare prototype om op voort te bouwen. Het bevat:

- **Dashboard** — overzicht van openstaand nakijkwerk, voortgang per klas en snelkoppelingen.
- **Nakijksysteem** — een rubric-gebaseerd beoordelingsscherm met voorbeeldverslagen
  (nog geen bestandsupload), waarin de docent per criterium scoort, feedback typt en
  het eindoordeel altijd zelf bepaalt.
- Geen inlogsysteem — direct te gebruiken.
- Huisstijl in wit met paars (met gradient).

Alle data in dit prototype is voorbeelddata; er is nog geen backend of opslag.

## Ontwikkelen

```bash
npm install
npm run dev
```

Bouwen voor productie:

```bash
npm run build
```
